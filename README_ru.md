## Подписать письмо

Люди и организации могут подписаться, добавив одну запись в [`supporters.jsonc`](supporters.jsonc) и отправив pull request. Менять HTML или запускать сайт локально не нужно.

Примеры и правила — в [CONTRIBUTING.md](CONTRIBUTING.md#русский). Подписывайтесь только за себя или организацию, которую вправе представлять. Подписи проверяются перед публикацией. Если нужна аватарка, добавьте картинку в `avatars/` и укажите её путь в поле `avatar`, например `/avatars/your-name.jpg`.

## Скриншоты в PR

Каждый push в pull request заново собирает превью в Chromium: RU/EN, ширины 1440 и 375 px. Бот обновляет свой комментарий ссылкой на свежие скриншоты и указывает коммит. Для скачивания артефакта нужен вход в GitHub; файлы хранятся 14 дней. Проверке первого PR из чужого форка может понадобиться стандартное одобрение сопровождающего в GitHub.

Превью не публикует PR на сайт. Процесс со скриншотами имеет только права чтения; ссылку оставляет отдельный доверенный процесс, не выполняющий код PR.

## Публикация

Принятые изменения в `main` собираются в GitHub Actions и публикуются в ветку `deploy`. После успешной сборки сайт обновляется автоматически. Pull request проверяется перед принятием и не может запустить деплой напрямую.

## Запустить локально

Для сборки статики достаточно Python 3.10 или новее.

```sh
python3 tools/build.py
python3 -m http.server 8766 --bind 127.0.0.1 --directory build
```

Откройте http://127.0.0.1:8766/ для русской версии или `/en/` для английской.

- `templates/ru.html`, `templates/en.html` — шаблоны страниц; при изменении письма обновляйте обе версии.
- `supporters.jsonc` — люди и организации, поддержавшие письмо; внутри есть закомментированные примеры.
- `style.css`, `language.js`, `*.svg` — общие стили, переключение языка, копирование кода шильдиков и графика.
- `tools/build.py` — проверка записей сторонников и сборка обеих страниц.
- `tools/release.py` — создание списка файлов и контрольных сумм; GitHub Actions публикует сборку после изменений в `main`.
- `build/` — собранный сайт; не редактировать и не коммитить.

Обе версии и списки подписей доступны без JavaScript.

Локальные скриншоты, если нужны (Node.js 20 или новее):

```sh
npm ci --ignore-scripts
npx playwright install chromium
npm run preview
npm run test:preview-comment
```

Четыре PNG сохраняются в игнорируемый `output/pr-preview/`. Версия Playwright закреплена lockfile; он нужен только для разработки и PR-превью.
